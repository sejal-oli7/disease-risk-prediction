ABOUT MULTI

Multi Risk Disease Prediction

MULTI is a machine-learning-based health risk prediction system developed as part of the HealthCare platform. It helps users organize patient information, provide required health parameters and receive estimated risk results through a simple and understandable interface.

PROJECT OVERVIEW

One platform for multiple disease risk assessments

MULTI brings patient management, health parameter collection, machine-learning prediction, prediction history and visual analytics together in one platform.

Users can manage multiple patients and perform risk assessments for Diabetes, Heart Disease, Kidney Disease, Liver Disease, Parkinson's Disease and Stroke.

PROJECT PURPOSE

Making machine-learning results easier to understand

The purpose of MULTI is to demonstrate how trained machine-learning models can be integrated into a web application and presented through clear risk levels, probability values and visualizations.

The system is designed for academic, educational and health-awareness purposes.

KEY FEATURES

Everything organized in one place

MULTI combines the essential features required for a complete disease risk prediction workflow.

Patient Management

Add and manage multiple patient records under a user account.

Machine Learning

Disease-specific trained models process the required health parameters.

Risk Analytics

Prediction results are presented using probability values and visual analytics.

Prediction History

Users can review their previous prediction records and risk results.

Secure Access

Authentication and protected APIs help secure user-specific application data.

Administration

Administrators can monitor users, patients and prediction records through the admin panel.

TECHNOLOGY

Built with web and machine-learning technologies

The system combines a Python backend, database, machine-learning models and a lightweight frontend.

Flask & Python

Used for backend development, routing, APIs and machine-learning integration.

PostgreSQL

Stores user accounts, patient information and prediction records.

Scikit-learn

Used for training and integrating disease-specific machine-learning models.

HTML, CSS & JavaScript

Provides the responsive frontend interface without a frontend framework.

Chart.js

Provides visual representations of prediction and risk analytics.

JWT Authentication

Protects authenticated application features and user-specific API access.

ACADEMIC PROJECT

Developed to demonstrate practical integration of machine learning and web development.

MULTI demonstrates the complete process of connecting trained machine-learning models with a web application, database and user interface.

The project focuses on learning and demonstrating machine learning, backend API development, database management, authentication and data visualization within a single application.

Medical disclaimer: MULTI provides estimated risk results for educational and health-awareness purposes only. It is not a medical diagnosis and should not be used as a substitute for professional medical advice, diagnosis or treatment.

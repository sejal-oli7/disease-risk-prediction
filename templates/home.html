FAQ

Frequently asked questions

Is this a medical diagnosis?

No. The system provides a machine-learning-based risk estimate for awareness and educational purposes. It cannot replace professional medical diagnosis.

How accurate are the predictions?

Each model is trained and evaluated using its corresponding dataset. Prediction performance depends on the model and the quality of the input values.

What information do I need?

Each disease module requires different health parameters. The prediction page displays the required inputs for the selected disease.

Is my data safe?

User authentication and protected API access are used to help keep account and prediction records secure.

Do I need to create an account?

Yes. An account is required to manage patients, generate predictions, save prediction records, and view prediction history.

Medical disclaimer: MULTI provides machine-learning-based risk estimates for educational and health-awareness purposes only. Results are not a substitute for professional medical advice, diagnosis or treatment.

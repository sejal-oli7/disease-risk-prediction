# Disease Risk Prediction System

A machine learning-based web application that predicts the estimated risk of multiple diseases using health-related parameters provided by the user.

The system supports both **manual health-parameter-based prediction** and **PDF health report analysis**. It provides disease-specific risk results and stores prediction history for authenticated users.

> **Disclaimer:** The results generated by this system are estimated predictions based on the available health parameters and are intended for health awareness and educational purposes only. They are **not a medical diagnosis** and should not be used as a substitute for professional medical advice.

## Machine Learning

The system uses disease-specific machine learning models for prediction.

Different classification algorithms were explored during model development, including:

* Logistic Regression
* Decision Tree
* Random Forest
* Gradient Boosting
* K-Nearest Neighbors (KNN)
* Support Vector Machine (SVM)
* Gaussian Naive Bayes
* XGBoost

The trained models are saved and loaded using **Joblib** for making predictions through the Flask application.

Each disease has its own model and required input features.

## Risk Classification

The system converts the model's predicted probability into an understandable risk level.

|   Probability | Risk Level |
| ------------: | ---------- |
| Less than 30% | Low        |
|     30% – 69% | Medium     |
|  70% or above | High       |

These risk levels represent model-estimated risk and do not represent a medical diagnosis.

## PDF Health Report Analysis

The system supports uploading a health report in PDF format.

The PDF analysis process works as follows:

```text
PDF Upload
    |
    v
PyMuPDF Text Extraction
    |
    v
Regex-based Parameter Extraction
    |
    v
Required Parameter Validation
    |
    v
Disease-specific Feature Preparation
    |
    v
Machine Learning Prediction
    |
    v
Risk Result
```

### How it works

1. The user uploads a PDF health report.
2. The system extracts text from the PDF using **PyMuPDF**.
3. Regular expressions are used to identify required health parameters.
4. The system checks whether the required parameters for each disease are available.
5. Prediction is performed only when sufficient required information is available.
6. The result is displayed as Low, Medium, or High risk.

If required information is missing, the system avoids generating an unreliable prediction for that disease.

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/disease-risk-prediction.git
cd disease-risk-prediction
```

### 2. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate the environment:

#### Linux / macOS

```bash
source .venv/bin/activate
```

#### Windows

```bash
.venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

## Environment Configuration

Create a `.env` file in the project root:

```env
SECRET_KEY=your_secret_key
JWT_SECRET_KEY=your_jwt_secret_key
DATABASE_URL=postgresql://username:password@localhost/disease_prediction
```

Do **not** commit `.env` to GitHub.

## Limitations

* Prediction results depend on the quality and limitations of the training datasets.
* The system does not provide medical diagnosis.
* PDF extraction depends on the structure and readability of the uploaded document.
* Different PDF formats may use different parameter names or layouts.
* Predictions cannot be generated reliably when required parameters are missing.
* The system is developed primarily for academic, educational, and health-awareness purposes.
